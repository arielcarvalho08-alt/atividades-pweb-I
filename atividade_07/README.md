# Atividade 07

Este diretório contém o desenvolvimento da Atividade 07 para a disciplina de Programação Web I.

📁 Estrutura do Projeto
- bin/www: Script de inicialização do servidor HTTP.
- public/stylesheets/: Contém os arquivos de estilos CSS da aplicação.
- routes/: Diretório contendo a modularização das rotas (`index.js` e `users.js`) utilizando `express.Router`.
- views/: Contém os arquivos de visualização (templates EJS) para renderização das páginas.
- app.js: Configuração principal da aplicação Express.

🎯 Escopo da Atividade
1. Modularização com Router: Refatoração do exercício da Aula 6 (Express) para desacoplar as rotas utilizando instâncias de `express.Router`.
2. Organização Estrutural: Separação limpa de endpoints e lógica de rotas em arquivos dedicados.

Para instruções detalhadas de como instalar as dependências e rodar o servidor, consulte o arquivo `package.json`.
