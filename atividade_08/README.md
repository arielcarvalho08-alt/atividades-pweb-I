# Atividade 08

Este diretório contém o desenvolvimento da Atividade 08 para a disciplina de Programação Web I.

📁 Estrutura do Projeto
- bin/www: Script de inicialização do servidor HTTP.
- public/stylesheets/: Contém os arquivos de estilos CSS da aplicação.
- routes/: Módulos de rotas do Express (`index.js` e `users.js`).
- views/partials/: Diretório dedicado aos componentes reutilizáveis de template (`header.ejs` e `footer.ejs`).
- views/: Contém as páginas EJS principais da aplicação.
- app.js: Configuração principal do Express e motor de templates.

🎯 Escopo da Atividade
1. Aplicação de Templates: Evolução do exercício anterior da Aula 7 utilizando motores de visualização (Template Engines).
2. Layouts Parciais: Implementação de cabeçalho (`header`) e rodapé (`footer`) compartilhados via diretório `/partials` para evitar duplicação de código HTML.

Para instruções detalhadas de como instalar as dependências e rodar o servidor, consulte o arquivo `package.json`.
