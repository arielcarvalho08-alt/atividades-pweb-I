# Atividade 16

Este diretório contém o desenvolvimento da Atividade 16 para a disciplina de Programação Web I.

## 📁 Estrutura do Projeto

* **`apihello/`**: Pasta principal contendo o servidor backend desenvolvido em Node.js com Express e a interface de testes em HTML.

## 🎯 Escopo da Atividade

1. **Monitoramento e Logs (v1):** Implementação de um middleware global para exibir logs de saída no console no formato `data/hora, endpoint, saída (JSON)`.
2. **Evolução da API (v2):** Criação da versão 2 da API com suporte a múltiplos idiomas (`pt-br`, `en`, `es`), recebendo os parâmetros tanto via URL (GET) quanto via formulário (POST).
3. **Disponibilidade:** Manutenção e coexistência de ambas as versões (`/v1` e `/v2`) operando simultaneamente no mesmo servidor.
