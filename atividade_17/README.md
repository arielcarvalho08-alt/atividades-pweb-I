# Atividade 17

Este diretório contém o desenvolvimento da Atividade 17 para a disciplina de Programação Web I.

📁 Estrutura do Projeto
- views/: Contém os arquivos de template em EJS para exibição das páginas.
- app.js: Arquivo principal do servidor Node.js/Express responsável por integrar a aplicação e consumir a API externa.

🎯 Escopo da Atividade
1. Aplicação Mensagem do Dia: Desenvolvimento de um sistema web dinâmico consumindo dados externos.
2. Integração com API: Consumo da API pública *Ron Swanson Quotes* para exibição de frases aleatórias.
3. Stack Tecnológica: Utilização de Node.js, Express, EJS e Bootstrap para interface responsiva.

Para instruções detalhadas de como instalar as dependências e rodar o servidor, consulte o arquivo `package.json`.
