# Atividade 18

Este diretório contém o desenvolvimento da Atividade 18 para a disciplina de Programação Web I.

📁 Estrutura do Projeto
- index.html: Interface principal da aplicação contendo os campos de busca e a estrutura do carrossel.
- main.js: Script frontend responsável pelas requisições via Axios, manipulação de dados da API e controle do carrossel.
- style.css: Folha de estilos personalizada para a interface visual.

🎯 Escopo da Atividade
1. Consumo de API da NASA: Integração com as APIs APOD (Astronomy Picture of the Day) para busca de imagens e metadados astronômicos.
2. Filtragem Avançada: Implementação de filtros lógicos para selecionar apenas mídias do tipo imagem que não possuem restrição de copyright e que correspondem ao astro pesquisado.
3. Exibição Interativa: Renderização dinâmica dos resultados filtrados estruturados em um componente de carrossel funcional.

Para instruções detalhadas de como instalar as dependências e rodar o projeto, consulte o arquivo `package.json`.
